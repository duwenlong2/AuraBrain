✦AuraBrain Runtime
First connection

让你的模型，成为本地运行时的大脑。

先连接一个兼容 OpenAI API 的模型。完成后，AuraBrain 会把普通设置保存到你的用户配置目录，并把密钥交给 Windows 安全存储。

配置可以随时在 Runtime 设置中修改。密钥不会写入项目文件，也不会回显。

配置 AuraBrain

模型配置集中在 Settings 中，初始化只需要完成一次。

打开模型设置

在这里添加 OpenAI 兼容接口、模型地址和 API Key。API Key 只会保存到 Windows Credential Manager。
